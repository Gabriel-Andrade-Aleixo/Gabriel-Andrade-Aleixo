# ⭐ Projetos em destaque

## 🎲 Runalith RPG

Sistema multiplataforma para gerenciamento de RPG, criado como um ecossistema composto por diferentes aplicações.

### Arquitetura

```text
Runalith
│
├── 📱 Flutter App
│   └── Fichas · Grimório · Dados
│
├── 🌐 Web App
│   └── Next.js · React · Three.js
│
├── ⚙️ Backend
│   └── Node.js
│
└── 🗄️ Database
    └── PostgreSQL
```

O projeto representa meu foco atual em desenvolver aplicações que compartilham regras, dados e serviços entre diferentes plataformas.

**Tecnologias:** `Flutter` `Dart` `Next.js` `React` `Three.js` `Node.js` `PostgreSQL`

[Ver projeto →](https://github.com/Gabriel-Andrade-Aleixo/rpg-sistema)

## ✈️ Registro de Viagens

Aplicativo desenvolvido em **Flutter** para registrar e gerenciar viagens.

O projeto trabalha com diferentes estratégias de persistência e comunicação com backend.

```text
Flutter
   │
   ├── SQLite ──────── Persistência local
   │
   └── HTTP
        │
        ▼
     Node.js
        │
        ▼
   PostgreSQL
```

Possui suporte a armazenamento local e integração com uma API remota.

**Tecnologias:** `Flutter` `Dart` `SQLite` `Node.js` `Express` `PostgreSQL`

[Ver projeto →](https://github.com/Gabriel-Andrade-Aleixo/Flutter-Registro-de-Viagens)
